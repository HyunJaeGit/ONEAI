## 검토 범위와 판단

홈을 포함한 HTML 16개와 공통 CSS·JS, 기존 검토 기록을 확인했다. 이번 작업은 기존 내용의 적용 범위와 정보 배치를 정리하는 작업이다. 원본 PDF 전체를 새로 검증한 작업은 아니며, 원문·사용자 안내에 없는 정책은 추가하지 않았다.

## 표현 원칙과 재점검

- 일반 절차·정상 상태·기본 표를 먼저 배치한다. OS별 준비·관리전환과 일반 펜슬 보급률은 정상 업무의 구분이므로 일괄 숨기지 않는다.
- 특정 상황·기기·한시사업은 기본 본문 뒤의 `해당하는 경우 추가 확인`에 모은다. 제목만 보고 적용 대상을 판단할 수 있게 한다.
- 보조 안내는 기본적으로 닫힌 네이티브 `details`로 구현한다. 회색 구획, 작은 제목·본문으로 계층을 구분하며 과도한 장식은 추가하지 않는다.
- 짧은 정상 업무 보충은 `manual-note`로 작게 표시한다. 미충전 수거 불가, 서명 후 잠금, 차단 해제 필수 등 실행 전 알아야 할 사항은 기본으로 계속 표시한다.
- 불확실한 기준을 일반 정책으로 확정하지 않는다. 기존 펜슬 기준 차이는 일반 제공 표 옆에 계속 표시하고, 조건부 항목의 불확실성은 접기 제목에도 `확인 필요`를 쓴다.
- 기존 `rubber-parts`, `pencil-exchange`, `repair-consent`, `cost-sharing`, `management-systems` ID를 유지한다. 해당 앵커 URL로 접근하면 안내가 자동으로 열린다.
- 검색 색인에는 접힌 내용도 포함한다. 검색 결과에서 이동하면 검색어가 있는 안내만 열리고 검색어가 강조된다.
- 인쇄 전에는 보조 안내를 모두 열고, 인쇄가 끝나면 원래 열림 상태를 복원한다. 인쇄 스타일도 보조 내용을 포함하도록 지정한다.
- 재배치·여분 기기는 기존대로 별도 업무 메뉴를 유지한다. 새로운 예외 정책이나 문의처는 만들지 않는다.

## 검증

- 전체 HTML 16개: 로컬 링크·자산 182개, 앵커 존재, 중복 ID, details 여닫는 태그 검사 통과. 업무·문의 페이지 13개에서 추가 확인을 마지막에 배치했고, 보조 접기 항목 37개를 확인했다.
- 전체 HTML 검색 색인 갱신. 공개 본문만 색인에 포함한다.
- Chrome headless 실제 DOM에서 18개 검사 통과: 기본 접힘, 일반 전용펜 행·수거 기준의 분리, 루버·펜슬·수리동의서 직접 링크 자동 펼침, 수동 접기/펼치기, 인쇄 전 모두 펼침 및 이후 상태 복원, 일반 일정 절차의 예외 분리, 루버 검색 결과·자동 펼침·강조, 무관한 안내 접힘 유지, 390px 문서 가로 넘침 없음.
- 390px 화면의 삼성 크롬북 보조 안내를 스크린샷으로 확인했다. 제목·설명은 화면 안에서 줄바꿈되고 긴 표는 자체 영역에서 가로 스크롤된다.
- 인쇄 검증은 브라우저의 beforeprint/afterprint 이벤트와 DOM 상태를 사용했다. 실제 프린터 출력이나 인쇄 대화상자를 수동 검증한 것은 아니다.

## 후속 반영: 펜슬 안내 별도 페이지

- 펜슬 관련 상세의 양이 많고 일반 제공과 한시적 교환을 함께 비교할 필요가 있어 pages/business/pencil.html로 통합했습니다. 앞 표의 설치 페이지 상세 설명은 이후 별도 페이지로 이동한 상태입니다.
- 기본 취급·정상 보급률은 먼저 표시하고, 계산 예시와 한시사업은 접는 구조를 유지합니다. 다른 업무 페이지에는 짧은 요약과 해당 상세로 가는 링크만 제공합니다.
- 기존 설치 페이지 앵커는 연결 안내로 유지하고, 사업 기본 흐름과 별도인 품목별 상세 안내로 진입하게 했습니다. 전체 페이지는 17개이며 검색에도 새 페이지가 포함됩니다.
