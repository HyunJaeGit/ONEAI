로컬 요청 제한 · ADMIN 로그인 필요

문서를 선택하면 미니맵에 섹션과 블록 순서가 표시됩니다. 항목을 선택해 편집 위치로 이동하고, 제목·문단·목록·안내·표·접기와 제한된 링크·강조를 화면 입력란으로 수정합니다.

관리자 화면과 API에는 loopback 요청 제한과 ADMIN 로그인이 모두 필요합니다. loopback은 로컬 개발 제한이며 운영 배포용 접근 제어를 대신하지 않습니다. 외부 네트워크에 공개하지 마세요. 저장한 변경은 일반 매뉴얼에 즉시 반영됩니다.
