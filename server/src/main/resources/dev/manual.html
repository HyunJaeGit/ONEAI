편집 도움말

미니맵이나 페이지 구조에서 영역을 클릭하면 오른쪽 속성 패널에서 편집할 수 있습니다. 우클릭 메뉴로 빠른 작업을 열 수도 있습니다. 카드 제목의 손잡이를 드래그해 같은 단계의 섹션·블록 순서를 바꾸고, 키보드는 Shift+F10 또는 Alt+위/아래 화살표를 사용하세요.

편집기 크기 조절은 입력 화면만 확대·축소하며 일반 페이지의 출력 크기에는 영향을 주지 않습니다. 저장 전 미리보기에서 화면을 확인할 수 있습니다.

문서 ID·버전·경로와 기존 앵커는 직접 바꾸지 않습니다. 삭제한 블록의 앵커는 사라질 수 있습니다. 저장하지 않은 내용은 문서를 바꾸거나 다시 불러올 때 확인하며, 저장 실패 시 입력 내용은 화면에 남습니다.

이 페이지와 관리 API는 ADMIN 로그인 및 loopback 요청이 필요합니다. loopback은 로컬 개발 제한이며 운영 배포용 접근 제어를 대신하지 않습니다. 외부 네트워크에 공개하지 마세요. 저장한 변경은 일반 매뉴얼에 즉시 반영됩니다.
