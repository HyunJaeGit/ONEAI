수집 이벤트 조회

로컬 전용 · 읽기 전용

검색·결과 노출·문서 클릭·조회 흐름을 확인하는 개발자 화면입니다. USERID는 인증 계정이 아닌 분석용 라벨이며, 테스트에는 합성 ID와 테스트 검색어만 사용하세요.

  1. 백엔드 실행
    Spring Boot 서버를 실행한 상태에서 사용합니다.
  2. 이벤트 만들기
    매뉴얼로 이동해 분석용 USERID를 입력하고 검색하거나 문서를 엽니다.
  3. 결과 확인
    이 화면으로 돌아와 새로고침하고 사건 카드를 펼쳐 상세 내용을 봅니다.
