OS별 준비

학교가 할 일

?

이 단계에서 학교가 진행할 절차입니다.

모든 OS에서 개인데이터 삭제 여부를 확인합니다. 차단 정책 해제는 학교가 관리자 계정으로 직접 수행하며, 수거담당자는 완료 여부를 확인합니다.

OS별 수합 전·후 준비
OS수합 전·학생 점검수합 완료 후 학교 작업
안드로이드FamilyLink 로그아웃, 화면 잠금 ‘설정 안 함’, 개인데이터 삭제, 구글·삼성 계정 로그아웃로그아웃 확인 후 AMA·Android 정책 모두에서 공장초기화·USB 전송 차단 해제
아이패드학교가 먼저 계정 로그아웃 차단을 허용. 학생의 개인데이터 삭제, 화면 잠금 해제, ASM 계정 로그아웃공장초기화, USB 제한 모드·USB 파일 연결, 외부 PC 페어링 차단을 허용으로 변경
윈도우개인데이터 삭제USB 제한 모드·USB 파일 연결 차단 해제
크롬북개인데이터 삭제구글 관리 콘솔에서 파워워시·게스트 모드 허용
웨일북개인데이터 삭제, 웨일스페이스 계정 로그아웃웨일스페이스 어드민에서 양품화 단말을 관리 기기에서 제외

확인 방법

  • 안드로이드: 적용된 AMA·Android 정책을 모두 확인합니다. 차단 목록의 공장초기화·USB 전송을 허용하고 저장합니다.
  • 아이패드: 적용 정책 [상세] → 차단 영역 [수정]에서 계정 설정, 공장초기화, USB 관련 항목과 외부 PC 페어링을 확인합니다.
  • 윈도우: 적용 정책 [상세] → 차단 영역 [수정]에서 USB 제한 모드·USB 파일 연결을 허용하고 저장합니다.
  • 크롬북: 구글 관리자 페이지의 기기 → 설정 → 해당 조직 단위에서 파워워시 허용과 게스트 모드 허용 상태를 확인합니다.
  • 웨일북: 시간 영역 → 전원 → 로그아웃을 확인합니다. 어드민의 Whalespace 관리 기기 → 모든 기기 보기 → 대상 선택 → 관리 기기에서 제외 후 안내에 동의하고 확인합니다.

안드로이드는 개별 [저장] 후 하단 [변경 사항 저장] → [확인]까지 진행합니다. 아이패드·윈도우에는 이 하단 메뉴가 없을 수 있으므로 표시 여부를 확인하세요.

준비 시 필수 확인

초기화 차단 해제는 필수, 기기 초기화는 선택입니다. 계정 삭제·로그아웃·차단 해제와 초기화 실행을 같은 작업으로 안내하지 마세요. 웨일북은 별도 초기화 차단 기능과 관계없이 관리 기기에서 제외해야 합니다.
